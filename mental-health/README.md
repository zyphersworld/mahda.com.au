# Right Now — mental health status page

Personal, unlisted (`noindex, nofollow` is set — this is a direct-link-only
resource, not meant to be found by search). Drop the `mental-health/`
folder into the web root so it serves at `mahda.com.au/mental-health/`.
Same engine as your other sites: `pages.json` drives content, hash router,
six liveries, baked JS fallback for offline reading.

## Before sending this to anyone

Read the "Right now" page again. It should be current and true today, not
just accurate as of when it was written. Update the date in `pages.json`
(`meta.updated`) whenever the content changes.

## No analytics on this one, deliberately

Unlike the other sites, this build has zero tracking of any kind — no GTM,
no GA, nothing. Whoever you send this link to shouldn't be logged for
reading it.

## The five pages

Right Now (editable status, your own voice) · The Pattern, Plainly
(factual explanation of what's been happening) · If You're Trying to Help
(concrete guidance for people around you) · Who to Call (real numbers) ·
Common Questions (FAQ).

## This is a fresh build, not the original

An earlier version of this site was built in a different conversation this
container doesn't have access to. This is rebuilt from scratch on the same
architecture, with updated content reflecting what's been disclosed since —
not an edit of that original file. Worth checking the wording against what
you actually want said before it goes to anyone.
